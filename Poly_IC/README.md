# GitHub Pages Website Starter

This folder contains a complete static website you can host on GitHub Pages.

## Files

- `index.html` - page structure
- `styles.css` - design and responsive layout
- `script.js` - mobile menu, animations, footer year

## Deploy on GitHub Pages

1. Create a new GitHub repository (for example: `my-website`).
2. Upload all files from this folder to the repository root.
3. On GitHub, go to `Settings` -> `Pages`.
4. Under `Build and deployment`, set:
   - `Source`: `Deploy from a branch`
   - `Branch`: `main` (or `master`) and `/ (root)`
5. Click `Save`.
6. Wait 1-3 minutes, then open your site URL shown on the Pages settings screen.

## Customize quickly

- Replace `YourName` and `Your Name` in `index.html`.
- Replace `you@example.com` with your email.
- Update the project cards with real links.
- Edit colors in `:root` in `styles.css`.

## Optional custom domain

If you have a domain, add a `CNAME` file in the root with your domain, then configure DNS in your domain provider.
